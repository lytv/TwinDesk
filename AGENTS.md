## Build / test

- Android app: `android/` (Gradle). Shared wire protocol: `shared/protocol.js` — keep `android/.../Proto.kt` and `ios/TwinDesk/Proto.swift` in step with it.
- iPad app: `ios/` (Xcode project generated by XcodeGen from `ios/project.yml`). After adding files: `cd ios && xcodegen generate`. Build: `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild -project ios/TwinDesk.xcodeproj -scheme TwinDesk -destination 'platform=iOS Simulator,id=<udid>'`.
- Wire `os` for the iPad is `"android"` (not `"ios"`): computers gate phone features on `os === 'android'` in `shared/protocol.js`. Do not invent a new OS value without a coordinated computer-side gate.
- iPadOS gaps (no SMS, no notification listener out, no accessibility drive, no flavors) are deliberate fallbacks documented on PR #1 / firstmate needs-decision `ipad-platform-gaps`.
